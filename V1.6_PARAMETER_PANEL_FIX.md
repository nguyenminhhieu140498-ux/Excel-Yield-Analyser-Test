## Parameter panel restoration hotfix

The v1.6 compact launcher now explicitly restores the original parameter controls widget into the left input pane, keeps its existing controls/layout and event connections, and gives the pane a usable minimum width. The chart/table preview and compact zoom behavior remain in place.

Run with Python 3.15:

```bash
python3.15 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pytest -v
python engineering_chart_analyzer_v16_compact.py
```
