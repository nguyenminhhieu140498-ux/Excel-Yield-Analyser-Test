# Excel Yield Analyzer — v1.6 DEBUG

The existing v1.4 DEBUG launcher and data workflows are retained. The v1.6 launcher adds clearer measurement/vendor axes, numeric box plots by selected measurement point, high-resolution preview with wheel/trackpad and Zoom controls, a vertical splitter between charts and summary/fail tables, persistent Fail SN pane, report rounding to two decimal places and an option to open reports after export. It also provides wider measurement/value controls and retains shift-range selection in the multi-select list.

Run under Python 3.15:

```bash
python3.15 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pytest -v
python engineering_chart_analyzer_v16_debug.py
```
