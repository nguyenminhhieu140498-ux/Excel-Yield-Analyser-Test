# v1.6 compact launcher regression fixes

The compact launcher no longer calls `FigureCanvasQTAgg.viewport()` (the canvas is not a QAbstractScrollArea). It installs gesture handlers on the canvas and table widgets/viewports safely. The spec validator returns ranges in X-axis order regardless of CSV row order, and commonality data keeps the stable `Vendor`/`Breakdown` column names expected by existing clients.
