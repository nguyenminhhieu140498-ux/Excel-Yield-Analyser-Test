## Boolean fail-mask hotfix

The v1.4 DEBUG launcher now applies duplicate handling to a fail mask aligned to the complete original input rows before any SN filtering. This prevents a Boolean index length mismatch when some SN cells are blank. The default Keep last + NG behavior is preserved.

Run the patched launcher with `python engineering_chart_analyzer_v14_debug.py` and verify with `python -m pytest -v`.
